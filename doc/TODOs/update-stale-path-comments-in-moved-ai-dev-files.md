# Update stale path comments in moved `myconfig.ai.dev` files

This file tracks stale **relative-path references inside comments and
docs** that piled up as directories moved from `modules/myconfig.ai/` into
`modules/myconfig.ai.dev/` (bd: myconfig-e4j). Files whose content is
**hashed into derivation output paths** (interpolated into strings, copied
into the store, or deployed as home-file sources) must keep byte-stable
content in pure-move commits, so comment fixes are deferred here.

The bulk of the stale comments in *imported* (non-embedded) files was
already fixed in the myconfig-e4j.6 sweep commit; the entries below are
what remains.

## Remaining (derivation-embedded — do NOT edit casually)

- `modules/myconfig.ai.dev/fns/seed-agent-config.nix`
  - comments say `../myconfig.ai.microvm/...` and `../programs.herdr.nix`;
    correct paths are now
    `../sandboxes/myconfig.ai.microvm/...` and
    `../programs/programs.herdr.nix`.
  - This file is interpolated into
    `modules/myconfig.ai.dev/sandboxes/myconfig.ai.qemu-agent-sandbox/default.nix`
    (`seedAgentConfig = ${../../fns/seed-agent-config.nix};`)
    and copied into the store verbatim, so its content hash feeds directly
    into the `agent-qemu-pi` / `agent-qemu-herdr` runner derivation paths.
    Fix together with the qemu files below in one cleanup commit.

- `modules/myconfig.ai.dev/sandboxes/myconfig.ai.qemu-agent-sandbox/`
  (`default.nix` imports `${./.}/runner.nix`, so the whole directory is
  copied into the store — even comment bytes change the runner outPath):
  - `builders.nix`: comments say `modules/myconfig.ai/fns/seed-agent-config.nix`,
    `modules/myconfig.ai/programs.pi-coding-agent/default.nix`,
    `modules/myconfig.ai/myconfig.ai.workmux/sandbox.nix`,

    correct is `modules/myconfig.ai.dev/...` throughout
    (`.../fns/`, `.../programs/`, `.../sandboxes/`, `.../myconfig.ai.workmux/`).
  - `default.nix` line ~33's runnerExpression interpolates this directory.

- `modules/myconfig.ai.dev/programs/programs.herdr.nix` line ~223:
  the `herdrConfigCommon` string literal contains
  `# Generated by NixOS (modules/myconfig.ai/programs.herdr.nix).` — this
  string is the content of the generated `~/.config/herdr/config.toml`
  file, so changing it changes that home file's store path.
  Correct would be `modules/myconfig.ai.dev/programs/programs.herdr.nix`.

  (`myconfig.ai.skills.handcrafted.rtk = ./skills/rtk` in
  `programs.rtk/default.nix`), so its bytes feed the deployed store path.

- `modules/myconfig.observability/scripts/myconfig-ccusage-refresh.sh`
  line ~28 says `modules/myconfig.ai/programs.ccusage`; correct is
  `modules/myconfig.ai.dev/programs/programs.ccusage`. The script is
  `replaceVars`-embedded into the `myconfig-ccusage-refresh`
