# Drop the opencode node_modules hash override

## What is pinned

`flake.pkgs_overrides.nix` overrides `pkgs.opencode` so the nested
`opencode-node_modules` fixed-output derivation gets the corrected
`outputHash`:

```nix
opencode = prev.opencode.overrideAttrs (old: {
  node_modules = old.node_modules.overrideAttrs (_: {
    outputHash = "sha256-prx9dX7kUvs/E3zopkaPk5LXh3xJAy5sZeum/W8L7cA=";
  });
});
```

## Why (upstream bug)

nixpkgs PR #581607 (opencode 2.1.1 → 2.2.5, merged 2026-11-02) pinned the
`node_modules` FOD hash as
`sha256-xfOVcw1+waLVNhFDwzOtzxrUSQEogvn88YomydOlhwc=`. That hash was
computed before bun 1.4.2 → 1.4.4 (PR #577354, merged hours later), so
`bun install --frozen-lockfile` now produces a different tree and every
opencode closure build fails with:

```
error: hash mismatch in fixed-output derivation '...-opencode-node_modules-2.2.5.drv':
         specified: sha256-xfOVcw1+waLVNhFDwzOtzxrUSQEogvn88YomydOlhwc=
            got:    sha256-prx9dX7kUvs/E3zopkaPk5LXh3xJAy5sZeum/W8L7cA=
```

Observed in `../_logs/2026-11-04-myconfig-f13.log` (f13 toplevel build);
~90 `Cannot build` errors all trace back to this single drv.

Upstream tracking:

- Issue: https://github.com/NixOS/nixpkgs/issues/582673
- Fix PR (same corrected hash, built on x86_64-linux, aarch64-linux,
  aarch64-darwin): https://github.com/NixOS/nixpkgs/pull/582675

The hash is platform-independent: the FOD installs with `--os="*"` /
`--cpu="*"`, and the same mismatch was reported on aarch64-darwin with a
matching x86_64-linux build in PR #582675.

`opencode-desktop` inherits `node_modules` from `opencode` via
`inherit (opencode) ... node_modules ...` (resolved through the callPackage
scope), so it picks up the fix through the same overlay.

## What to do

1. Check whether PR #582675 has been merged AND the `nixpkgs` flake input
   has been updated past the merge commit:

   ```bash
   gh pr view 582675 --repo NixOS/nixpkgs --json state,mergedAt,mergeCommit
   ```

2. Once merged and the input is bumped (`nix flake update nixpkgs`), delete
   the `opencode` overlay block in `flake.pkgs_overrides.nix` (search for
   "opencode:") and its row in the header table.

   If nixpkgs later bumps opencode beyond 2.2.5, the override still only
   re-pins the FOD hash of *that* version's `node_modules`, so it would
   fight a fresh upstream hash — do not keep it around past the fix.

3. Verify:

   ```bash
   nix build --dry-run .#nixosConfigurations.f13.config.system.build.toplevel
   ./build-pkg-for-host.sh opencode f13
   ```
